The first public release of Rowkery: a keyboard-first Mac app for Postgres and SQLite, with an MCP server built in so your AI agent can read your data while only you change it.

## Working with your data

- **Postgres and SQLite.** Connect to Postgres directly, over SSL or through an SSH tunnel, or paste a `postgres://` URL to fill in a new connection. ⌘O opens a SQLite file. A small sample database is there on first launch to try things on.
- **Keyboard first.** ⌘K finds any table, recent query, connection or command. Hold ⌘ to see the keys for what's on screen; ⇧⌘/ lists them all. The mouse works everywhere too.
- **Query tabs** each keep their own session, so `SET` and `BEGIN … COMMIT` carry across runs. ⌘↵ runs the statement under the caret, and Esc or ⌘. cancels it. Load more fetches the next page of results, and Export… writes CSV, TSV, JSON or SQL INSERTs.
- **Table tabs** show the exact SQL behind the rows, with your filters as chips in its WHERE. Sorting and paging run on the server.
- **Staged edits.** Change cells, insert, duplicate or delete rows, and the bar at the grid's foot counts the changes. Review SQL shows the exact transaction. Commit (⌘S) runs it, and rolls it back unless every statement changed exactly one row.
- **Readable query plans.** ⌘E shows a statement's plan as a short tree, with the slowest step marked and at most one plain hint. On Postgres, Explain with timings runs the statement for real and rolls it back.
- **Sessions** (⌘K, Show sessions) lists what's running on a Postgres database, blocked and blocking sessions first. Pick one to see its locks and query, then cancel it or end it.

## Staying safe

- **Environments.** Tag each connection prd, stg, dev or local, and its window pill carries the colour.
- **Safe mode.** Confirm writes stops every write and shows the exact SQL before it runs. Read-only refuses writes, and its sessions are read-only on the server too.
- **Presenting** hides sensitive columns and the host line on screen while you share it. Copy still copies the real value.
- **Undo.** Closing a tab or a window, deleting a connection and discarding edits all offer Undo.
- Passwords stay in your macOS Keychain. There's no account and no sign-in.

## Agents

- Rowkery runs as a stdio MCP server (`Rowkery --mcp`). The Agents page connects Claude Code or Claude Desktop in one click and shows the command for any other MCP client.
- An agent sees only the connections, databases and tables you share, for as long as you choose. Every query is a single SELECT on a read-only session with a row cap and a time limit. A query that would read a big table end to end is refused.
- **Sensitive columns.** Mark a column and agents only ever get a stand-in for its values. They can still count and match on it, but they can't filter or sort by it.
- **Proposed changes.** An agent can send an INSERT, UPDATE or DELETE with its reason. Rowkery dry-runs it and shows you the rows before and after. Nothing is written until you press Commit.
- Every call lands in the activity log on the Agents page, with its request and the start of its response.

## Install

1. Open `Rowkery.dmg` and drag Rowkery to Applications.
2. Rowkery isn't signed by Apple yet, so macOS blocks the first launch. Choose **Open Anyway** in System Settings > Privacy & Security, or run this in Terminal:

   ```
   xattr -dr com.apple.quarantine /Applications/Rowkery.app
   ```

Rowkery checks for updates after launch and installs them when you restart it. **Help > Check for Updates…** checks right away.

## Requirements

macOS on Apple Silicon or Intel. One universal build covers both.

## Known limits

- Sessions and Explain with timings work on Postgres only.
- Because the app isn't signed, macOS asks again for Keychain access to each connection after an update.
- Linux and Windows build from source, but they aren't released or tested the way the Mac app is.
