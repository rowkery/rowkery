## New

- **Google Cloud SQL**: pick **Google Cloud SQL** under Postgres's **Connect to** and choose an instance. Rowkery connects through Google itself, with no Cloud SQL Auth Proxy to run. It signs in to Google with your gcloud login or a service account key kept in the Keychain.
- Running several statements lists each one's result beside the grid; pick one with a click or ↑ / ↓. A write says how many rows it changed.
- Query tabs load the whole result; the query's LIMIT decides how many rows come back. Load more, the page-size menu, Data / Structure and Copy all results as CSV are now on table tabs only.

## Fixed

- Couldn't connect reads a connection pooler's "SASL authentication failed" as a wrong password.
- **Delete…** in the connection form asks Keep / Delete first.
- Typing a row's first letters in a menu or filter picker moves to that row.
- + and ⌘T show the empty window if one is already open, and leave Agents or Settings.
- The Columns table lines up each row's cells.
- The update button shows under Automatic too, and an empty result reads No records.
