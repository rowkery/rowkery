## New

- **Health tab** for Postgres and SQLite databases: finds ids running out, old transactions, unused and duplicate indexes, foreign keys with no index, and more. It only reports; it runs no fix.
- **⌘Z steps back staged edits**, and **⌫** on a cell marks its row for delete.
- **⌘R** reloads the schema and the tab on screen; a query tab reruns only a read-only statement.
- The sidebar's row counts follow the rows the window has seen, not Postgres's estimate.
- Controls use soft fills instead of grey borders.

## Agents

- Agent activity has day headers over its calls.
- Each connection has its own agent query limit.
- A proposed change counts every row it touches.
- A grid commit that would reach other tables is stopped before it runs.
- A proposal commits only the rows its dry run showed.
- A commit cut short by a crash stays waiting and says so.
- A generated column built from a masked column stays masked.
- A type built on a code-backed type runs that code too.
- An aggregate whose steps are database code counts as database code.

## Fixed

- Postgres ranges, records, geometry, tsvector and n-d arrays show as psql shows them, and timestamptz uses the session's time zone.
- Postgres shows a real's own digits, explains SQL_ASCII values that aren't UTF-8, and shows the rows of any statement that returns them.
- Postgres DETAIL and HINT lines show with an error.
- Index key columns are listed, not pieces of the index definition.
- Other sessions' temp tables stay out of the schema list and the catalog cache.
- Safe mode counts server-changing functions as writes, and checks the tables in pushed-down foreign scans.
- Closing a tab never drops an open transaction, and closing a tab or window ties up its loose ends.
- A timed plan never rolls back a transaction it couldn't see.
- A run never waits for its tab's session to be replaced after a sleep.
- A quick double Esc is one cancel, not a Force stop.
- A pasted URL's password stays hidden, and `#?@` in it is read as psql reads it.
- A denied keychain prompt saves nothing.
- Cancel drops a pending Save, and a quick Save isn't lost.
- A slow keychain prompt no longer reads as the bastion not answering.
- SSH says when a key needs its passphrase, and which login the host refused.
- A changed SSH host key is forgotten from the error, and a first connect names the key it trusts.
- A quoted `'null'` is text, and contains works on any type.
- Update without the key mapped says so instead of inserting.
- A trigger's `BEGIN … END` body stays one statement in the editor.
- A long statement the SQL file scan couldn't read whole shows in red.
- Config is written to its own temp file and to disk before the rename.
- The app's files are readable by this user only.
- The Local Network prompt says why Rowkery needs it.
- An update says why it can't install, and keeps its download.
- The MCP connect step doesn't write down a path that won't last.
- Staged edits commit in one round trip, not two per row, and a cell of megabytes shows its start.
