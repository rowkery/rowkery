A fix for agents connecting through Rowkery's MCP server.

## Fixed

- **Agents now see a password you save or change while they're connected.** The MCP server kept the password it first read, so after you saved or changed a connection's password in the app, every agent call failed with "Postgres rejected password" until the agent restarted. A rejected login now reads the Keychain again and retries once.
- When no password reaches Postgres, the error now says why: macOS refused the Keychain read, or no password is saved for that connection.

## Install

Rowkery 0.1.0 offers this update after launch and installs it when you restart. **Help > Check for Updates…** checks right away.

For a new install, open `Rowkery.dmg` and drag Rowkery to Applications. Rowkery isn't signed by Apple yet, so choose **Open Anyway** in System Settings > Privacy & Security on the first launch, or run this in Terminal:

```
xattr -dr com.apple.quarantine /Applications/Rowkery.app
```

Because the app isn't signed, macOS asks again for Keychain access to each connection after the update.
