Rowkery 1.1.0 adds MySQL and MariaDB.

## New

- **MySQL and MariaDB connections.** Pick **MySQL · MariaDB** in the New connection form, or paste a `mysql://`, `mariadb://` or `jdbc:mysql://` URL. SSL and SSH tunnels work as on Postgres.
- Browse, filter and edit rows, Quick Look, Import CSV, Run SQL file (mysqldump and mariadb-dump files too), ⌘E plans, the Sessions view and the database picker (⇧⌘D) all work on MySQL and MariaDB.
- Safe mode covers MySQL: Read-only refuses stored functions and `INTO OUTFILE`, and switching the character set can't hide a write.
- Agents can't use MySQL or MariaDB connections yet, and the Health tab is Postgres and SQLite only for now.
- **Star Rowkery on GitHub** in the Help menu and ⌘K. After five days of use, a card in the schema column asks once.
