## New

- **Run SQL file**: File › Import SQL…, ⌘K or drop a .sql file. It streams through safe mode, whole file or per statement, with Stop or Keep going; Cancel rolls back a whole-file run.
- **Import CSV…**: File menu, ⌘K, a table's … menu, or drop a .csv / .tsv on the window. Columns match by name, the first 20 rows preview in an Import tab, and Cancel rolls back.
- **Schema map** (⌥⌘3): a third view on table tabs, with the tables a table points to and the ones pointing to it. **Guess links** draws customer_id → customers where there's no foreign key.
- A table opens in the view the last one showed, and the map keeps its reach per database.
- **Format SQL** (⌘I) lays out the statement under the caret, or every statement in the selection.
- **Rows in the chat**: in clients that draw MCP Apps views, query results show as a sortable grid and proposals as a live card. Open in Rowkery opens the query without running it; Review in Rowkery opens the proposal.
- The agent activity log shows each call's database and time, and marks failed calls.
- Quitting or closing the window asks first while a transaction, a write, an import or a SQL file run is open.
- Rounded inset sheets and pill tabs.

## Agents

- Masked columns stay masked through UNION, partitions and child tables.
- A hidden table's partitions and child tables stay hidden, in any schema.
- Agents are refused Postgres role password hashes, user mapping options and subscription connection strings, and column statistics when a column is masked.
- An agent's query is checked and run in one transaction, so what runs is what was checked.
- Queries take fewer round trips and use much less memory on big cells, and a slow one holds up only its own connection.
- list_tables lists up to 500 tables, search-path schemas first, and takes a schema filter.
- Agents can propose INSERTs into tables with serial or identity keys.
- Agents' SQLite connections open the file read-only.
- Foreign tables are labelled, for agents and in the app.
- "Allow MCP" now reads **Share with agents** everywhere.

## Fixed

- Postgres interval, inet, cidr, macaddr, bit and timetz show as text instead of placeholders like `<interval>`.
- Safe mode closes several ways a write could pass as a read.
- On Postgres with standard_conforming_strings off, a backslash in a key, filter or export value can't break out of its quotes.
- Sessions redacts a literal that follows a backslash string.
- A safe mode change or connection switch is refused, with a toast naming the tab, while a tab holds an open transaction.
- A server warning, like a COMMIT with no transaction, shows with the result.
- json and jsonb keep every digit.
- Copying cells gives quoted TSV, and pasting it back keeps NULLs. Copy all results stops at 100 MiB.
- Staged edits stay with the connection they were made on.
- A config.json that doesn't parse is kept instead of saved over.
- A Postgres port that accepts and then says nothing times out instead of hanging.
- Cancelling a SQLite run stops it, and SQLite tabs keep their connection between runs.
- A pasted URL with a stray % no longer blanks the window.
- The grid stays smooth while you type, and Find on a big result says Searching….
- Two Rowkery processes saving to the Keychain at once no longer undo each other's change.
- Esc that leaves a selection keeps your edits, and ↵ never presses the update toast's Restart.
- Ending a session from Sessions says End session.
- Patched advisories RUSTSEC-2026-0381, -0382, -0385, -0386 and -0387.
