# Connecting to agents

<p className="lead">Rowkery has an MCP server built in. An agent can read the databases and tables you share and nothing else. It can't change your data; a change it suggests waits for you to commit it.</p>

<Steps>

### Share a connection

Open the **Agents** page (<kbd>⇧⌘A</kbd>, or the Agents button at the foot of the schema column) and turn on the connection's switch. Choose how long: until you turn it off, for an hour, or for today.

**Edit access** narrows it to the databases, then the tables, the agent may read. [Choosing what to share](/choosing-what-to-share/) covers every option.

### Connect your agent

Choose **Connect an agent** on the Agents page, or **Connect Claude Code or Claude Desktop** in <kbd>⌘K</kbd>. Rowkery shows exactly what it will run before it runs it.

<Shot src="/img/connect-claude-desktop.webp" width={1300} height={576} alt="Connect an agent, Claude Desktop tab: the entry Rowkery will add to claude_desktop_config.json, with Copy entry, Cancel and Run." />

| Agent | What Rowkery does |
| --- | --- |
| Claude Desktop | Adds an entry to its config file and keeps everything else in it. Reopen Claude Desktop afterwards |
| Claude Code | Runs `claude mcp add --scope user rowkery -- …/Rowkery --mcp`. Start a new session afterwards |

### Any other MCP client

Add Rowkery as a stdio server. Most clients take this shape; [Other agents](/other-agents/) has the exact setup for Cursor, VS Code, Windsurf, Zed, Codex and more.

```json
{
  "mcpServers": {
    "rowkery": {
      "command": "/Applications/Rowkery.app/Contents/MacOS/Rowkery",
      "args": ["--mcp"]
    }
  }
}
```

### Ask it something

Try “Which tables are in my arcade database?” or “How many orders came in yesterday?”. Each call shows up on the Agents page as it happens.

</Steps>

## What the agent can call

[MCP tools](/mcp-tools/) has each tool's inputs and an example call.

| Tool | What it does |
| --- | --- |
| `list_connections` | The connections you share |
| `list_databases`, `list_tables` | What's shared on one connection |
| `search_schema`, `describe_table` | Find a column or table, and read its columns, keys and indexes |
| `query` | One SELECT, up to 1,000 rows, stopped after 10 seconds or the connection's query limit |
| `explain` | A query's plan, with the slowest step and one hint |
| `sessions` | What's running on the server, with values hidden |
| `propose_change`, `check_proposal` | Suggest an insert, update or delete, then see what you decided |

## What gets refused

Before anything reaches your database, Rowkery refuses:

- Writes of any kind, and more than one statement at a time
- Tables you haven't shared
- Queries that would read a large table from start to end
- Functions defined in your database, and functions that could affect other sessions, files on the server or its settings

The agent gets the reason back, so it can try a narrower query. [Choosing what to share](/choosing-what-to-share/#what-agents-can-never-do) lists every check, and [MCP tools](/mcp-tools/#refusals-and-errors) quotes each message.

## The activity log

<Shot src="/img/agents-page.webp" width={1600} height={1000} alt="The Agents page: three connections on the left with their sharing switches, the activity log on the right with queries, one refused." />

Every call is listed, newest first and grouped by agent session. Pick one to see what was shared at the time, the request as sent and the start of the response, which is kept for 24 hours unless you turn result samples off. [The activity log](/choosing-what-to-share/#the-activity-log) explains each part.

## When the agent proposes a change

A toast tells you a change is waiting, and the Agents button shows a count. Open it to see the agent's reason and SQL, try a **Dry run**, then **Commit** <kbd>⇧⌘↵</kbd> or **Discard**. Nothing is written until you commit. [Proposed changes](/proposed-changes/) walks through the review.

## Rows in the chat

In Claude Desktop and other clients that draw MCP Apps, the rows the agent gets show in the chat as a table you can sort, and a proposed change as a card that follows what you decide. **Open in Rowkery** opens the query in a tab. [Rows in the chat](/rows-in-the-chat/) shows both.

## Sensitive columns

Choose **Mark as sensitive** in a column header's menu and agents only ever get a stand-in for its values. **Presenting**, at the foot of the schema column, also hides them on your screen. [Sensitive columns and Presenting](/sensitive-columns-and-presenting/) says what agents can still do with a marked column.

## Stop sharing

Turn off a connection's switch, or press **Stop all sharing**. It takes effect on the agent's next call.
